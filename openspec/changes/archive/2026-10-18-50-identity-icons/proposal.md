## Why

The app icon, splash, notification icon, README header, macOS bundle icon, menu bar glyph and the installer banner still carry the first identity: Claude's spark over a terminal window, in Claude orange. Remote Harness now drives several agents and its product accent is amber (#152), so the artwork has to stop naming one agent (#84). The prototypes in `docs/design/identity/icons.html` fixed the mark ("the Tether": three reins from three terminals meeting in one ring) and every file that carries it.

## What Changes

- **The mark** ported from the prototype (`shared.js`) into `apps/mobile/scripts/icons.mts` as reusable SVG in two weights: regular (app icon, splash, README, landing) and bold (anything under 24 px: menu bar, notification icon, favicon, Live Activity).
- **Generated assets** (`pnpm --filter @remote-harness/mobile icons`), all from code, Claude spark and `>_` window gone:
  - `icon.png` 1024: dark vertical gradient `#1C1A17 → #0D0D0D`, amber radial glow centered low, regular mark in amber `#E8A33D` (640 px box at 192/182, as in the prototype). The macOS bundle icon (`AppIcon.icns`) is built by the installer from this same file, so it follows.
  - `adaptive-icon.png`: the mark inside the 66 % safe zone over transparent (background color from `app.config.ts`); `adaptive-icon-monochrome.png`: bold mark in white (Android themed icon).
  - `notification-icon.png` 96: bold mark in white. `favicon.png` 48: bold mark on the dark background. `live-activity-icon.png` 144: bold mark on the dark rounded square (#158 keeps it).
  - `splash-icon.png` 1024: regular mark in amber over transparent (the splash background stays `#0D0D0D`).
  - SVG sources in `apps/mobile/assets/icon/` (`mark.svg`, `mark-bold.svg`, `icon.svg`, `splash.svg`).
  - **Brand banner** `docs/brand/og.png` 1200×630: dark gradient, the mark, "Remote Harness", the tagline "Follow and drive your coding agents from your phone." and the agent chips (Claude Code, Codex, "+ soon"), rendered with JetBrains Mono from the app's bundled font files. It becomes the README header (both languages) and, later, the landing's Open Graph image (#135).
- **Menu bar glyph** (`apps/daemon/tray/macos/Tray.swift`): the bold mark drawn as a template `NSImage` (18 pt), replacing the `terminal` SF Symbol; working/waiting/offline states come with #160. **Linux**: a symbolic SVG of the bold mark shipped next to `tray.py` and registered through the indicator's icon theme path, falling back to `utilities-terminal` when it is missing.
- **Installer banner** (`apps/daemon/src/features/setup/banner.ts`): the block-character icon redrawn as the Tether (nodes muted, reins and ring in the accent), the words become REMOTE / HARNESS, the palette accent becomes amber and the welcome box glyph stops being the Claude spark. The logo still fits an 80-column terminal.
- README (en, pt-BR): the banner replaces the icon in the header. Screenshots stay for now: they will be retaken once the redesigned screens exist (#153–#157), as noted in the issue.
