## Context

`SubagentTracker` watches `<transcript folder>/<session>/subagents/agent-*.jsonl` with chokidar, keeps `session.subagents` (`agentId`, `agentType`, `description`, `state`, `updatedAt`) and broadcasts `subagent.updated`. The app shows a horizontal `SubagentStrip` on the session screen and `NestedSubagents` in the list. The prototypes (`docs/design/identity/screens/more-options-menu.html`, `subagents-sheet.html`) fix the copy: `Subagents (5 · 2 running)` in the menu, rows like `running · 1:12 · 4 tools` and `done · 3:05`.

## Decisions

- **Elapsed and tool count come from the daemon.** The app cannot read the transcript file, and the tracker already reacts to every change of it. `startedAt` is the file's birth time when the file is readable (so it survives daemon restarts), else the discovery time. `toolCount` is counted incrementally: per agent the tracker keeps the byte offset already consumed and the trailing partial line as bytes (a multibyte character cut by the read is not corrupted); on each change it reads only the appended bytes, splits the complete lines and counts the `tool_use` entries returned by `parseTranscriptLine`. Reads of one transcript are serialized, so a watcher event and an explicit touch cannot count the same bytes twice. A truncated file resets the cursor. The parser keeps ownership of the `.jsonl` format.
- **`SubagentStop` settles the count.** The hook can arrive before the last change event; after marking the subagent done the tracker consumes the file once more and corrects `toolCount` if it moved.
- **`done` keeps its duration.** For a finished subagent the sheet shows `updatedAt − startedAt`; for a running one `now − startedAt`, refreshed every second by `useNow`. Without `startedAt` (older daemon) the elapsed part is omitted.
- **Menu item only when there are subagents.** `sessionMenu` takes `subagents: { count, running }` and adds `subagents` right after `terminal` only when `count > 0` (the issue allows hidden or disabled; hidden avoids a disabled item whose explanation is about read-only sessions). Labels `Subagents (N)` / `Subagents (N · M running)` use a plain `{{n}}` so no plural form is involved.
- **Accent dot on the menu button.** `ActionMenu` gets `attention?: boolean` and draws a small accent circle over the icon, outlined with the surface color. No new control and no hex outside the theme.
- **Sheet, not screen.** `SubagentsSheet` is a `Modal` bottom sheet like the others; it receives `session.subagents` from the store so it updates live. A row navigates to `/session/[id]/agent/[agentId]` and closes the sheet. The iPad inspector tab (#159) will reuse its row list.
- **`formatElapsed` becomes shared** in `core/utils/time.ts` (`m:ss`, `h:mm:ss`); the waiting strip imports it from there.
